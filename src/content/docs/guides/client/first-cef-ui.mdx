The Chromium Embedded Framework (CEF) allows you to build custom heads-up displays (HUDs), inventory screens, interactive menus, and speedometer gauges using modern web technologies like HTML, CSS, and JavaScript.

In this guide, you will learn how to initialize a CEF browser overlay, handle cursor focus, and establish two-way communication between your game client and your web page in JavaScript and Lua.

---

<Steps>
1. ## Initializing the CEF Web View

   All web files (HTML, CSS, JS, images, fonts) must be explicitly listed in the `file` array inside your `resource.toml`. Otherwise, the server runtime will not stream them to clients.

   You can initialize CEF either statically via manifest configuration or dynamically via script:

   <Tabs syncKey="cef-init-method">
     <TabItem label="Via resource.toml (Recommended)">
       Set `cef_url` in `resource.toml` to load the entry page automatically when the resource starts:

       ```toml title="resource.toml"
       client_script = 'client.js' # or 'client.lua'
       cef_url = './ui/index.html'

       file = [
         "./ui/index.html",
         "./ui/style.css"
       ]
       ```
     </TabItem>
     <TabItem label="Via Client Script">
       Initialize the browser dynamically at runtime:

       <Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
         <TabItem label="JS">
           ```js title="client.js"
           // Create a CEF browser instance: mp.cef.createBrowser(url, isHidden, isTransparent)
           const browser = mp.cef.createBrowser('./ui/index.html', false, true);
           ```
         </TabItem>
         <TabItem label="Lua">
           ```lua title="client.lua"
           -- Sets the URL of the CEF browser (creates instance if not already existing)
           mp.cef.setUrl('./ui/index.html')
           ```
         </TabItem>
       </Tabs>
     </TabItem>
   </Tabs>

2. ## Building the Web UI Page

   Create `ui/index.html`. Inside the browser context, CyberMP injects a global `mp.events` object. You can emit events to the client script and listen for responses:

   ```html title="ui/index.html"
   <!doctype html>
   <html lang="en">
   <head>
     <meta charset="utf-8">
     <title>CyberMP UI</title>
     <style>
       body {
         margin: 0;
         padding: 24px;
         background: rgba(10, 10, 15, 0.85);
         color: #00f0ff;
         font-family: sans-serif;
         display: flex;
         flex-direction: column;
         align-items: center;
         justify-content: center;
         height: 100vh;
       }
       button {
         background: #ff003c;
         color: white;
         border: none;
         padding: 12px 24px;
         font-size: 16px;
         cursor: pointer;
         text-transform: uppercase;
         letter-spacing: 1px;
       }
       button:hover {
         background: #ff2b5d;
       }
     </style>
   </head>
   <body>
     <h2>CyberMP HUD</h2>
     <button id="send-btn">Send Data to Client</button>
     <p id="status-text">Waiting for input...</p>

     <script>
       const btn = document.getElementById('send-btn');
       const status = document.getElementById('status-text');

       btn.addEventListener('click', () => {
         // Emit an event to the client script
         mp.events.emit('uiClickEvent', 'Hello from the CEF browser!');
       });

       // Listen for events dispatched from the client script
       mp.events.on('acknowledgeData', (message) => {
         status.textContent = message;
       });
     </script>
   </body>
   </html>
   ```

3. ## Managing Focus and Event Routing

   When an interactive menu opens, you need to capture keyboard and mouse input. When it closes, release input back to the game:

   <Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
     <TabItem label="JS">
       ```js title="client.js"
       // Command to open UI and capture mouse/keyboard
       mp.commands.add('ui', () => {
         mp.cef.setFocus(true, true); // (keyboardFocus, mouseCursor)
         console.log('UI in focus:', mp.cef.isInFocus());
       });

       // Command to release focus back to the game
       mp.commands.add('closeui', () => {
         mp.cef.setFocus(false, false);
         console.log('UI in focus:', mp.cef.isInFocus());
       });

       // Handle events arriving from the CEF page
       mp.events.onCef('uiClickEvent', (message) => {
         console.log(`[Client Script] Received: ${message}`);

         // Send data back into CEF
         mp.events.emitCef('acknowledgeData', 'Data received by client script!');
       });
       ```
     </TabItem>
     <TabItem label="Lua">
       ```lua title="client.lua"
       -- Command to open UI and capture mouse/keyboard
       mp.commands.add('ui', function()
         mp.cef.setFocus(true, true) -- (keyboardFocus, mouseCursor)
         print("UI in focus:", mp.cef.isInFocus())
       end)

       -- Command to release focus back to the game
       mp.commands.add('closeui', function()
         mp.cef.setFocus(false, false)
         print("UI in focus:", mp.cef.isInFocus())
       end)

       -- Handle events arriving from the CEF page
       mp.events.addCef('uiClickEvent', function(message)
         print("[Client Script] Received: " .. message)

         -- Send data back into CEF
         mp.events.triggerCef('acknowledgeData', 'Data received by client script!')
       end)
       ```
     </TabItem>
   </Tabs>

4. ## Testing In-Game

   1. Connect to your server.
   2. Press `F8` to open the client console.
   3. Type `ui` and press Enter. The mouse cursor will appear over the screen.
   4. Click **Send Data to Client**. The status text updates with the confirmation payload.
   5. Type `closeui` in the F8 console to release cursor control back to character movement.
</Steps>

:::tip[Remote Debugging]
To inspect your HTML/CSS elements and JavaScript console inside CEF, set `cef_debug = true` in your `server.toml`. Then open a Chromium-based browser on your development machine and navigate to `http://localhost:9222`.
:::
