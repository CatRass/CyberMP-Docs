The Chromium Embedded Framework (CEF) allows you to build custom heads-up displays (HUDs), inventory screens, interactive menus, and speedometer gauges using standard web technologies (HTML, CSS, and JavaScript).

For complete method signatures and options, see the [`MpCef`](/reference/client/api/global/mpcef/) reference and the browser-side [`MpEvents`](/reference/browser/api/global/mpevents/) reference.

---

## Resource Manifest Configuration

All web assets (HTML, CSS, JavaScript, images, fonts) must be listed in the `file` array of your `resource.toml` manifest. Unlisted files will not be streamed to clients:

```toml title="resource.toml"
client_script = 'client.js' # or 'client.lua'
cef_url = './ui/index.html'

file = [
  "./ui/index.html",
  "./ui/style.css"
]
```

### Static vs Dynamic URL Configuration

- **Static**: Specifying `cef_url` in `resource.toml` automatically loads the page when the resource starts.
- **Dynamic**: You can load or change the page URL at runtime using `mp.cef.setUrl('./ui/index.html')` (the path must still be in the manifest's `file` array).

## Building the Web Page

Inside your resource directory, create `ui/index.html`. CyberMP injects a global `mp.events` object into the browser window context:

```html title="ui/index.html"
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>CyberMP UI</title>
  <style>
    body {
      margin: 0;
      padding: 24px;
      background: rgba(10, 10, 15, 0.85);
      color: #00f0ff;
      font-family: sans-serif;
      display: flex;
      flex-direction: column;
      align-items: center;
      justify-content: center;
      height: 100vh;
    }
    button {
      background: #ff003c;
      color: white;
      border: none;
      padding: 12px 24px;
      font-size: 16px;
      cursor: pointer;
      text-transform: uppercase;
      letter-spacing: 1px;
    }
    button:hover {
      background: #ff2b5d;
    }
    #status-text {
      margin-top: 16px;
      font-size: 14px;
      color: #8be9fd;
    }
  </style>
</head>
<body>
  <h2>CyberMP HUD Layer</h2>
  <button id="send-btn">Send Data to Client</button>
  <p id="status-text">Awaiting transmission...</p>

  <script>
    const btn = document.getElementById('send-btn');
    const status = document.getElementById('status-text');

    // 1. Dispatch an event to the game client script when clicked
    btn.addEventListener('click', () => {
      mp.events.emit('uiClickEvent', 'Hello from the CEF browser context!');
    });

    // 2. Listen for response data transmitted from the client script
    mp.events.on('acknowledgeData', (message) => {
      status.textContent = message;
    });
  </script>
</body>
</html>
```

For more details on browser-side event emission and listeners, see the [Browser Events API](/reference/browser/api/global/mpevents/).

## Managing Input Focus & Event Routing

When an interactive menu opens, capture keyboard and mouse input so clicks and keystrokes route to CEF rather than character movement. Release focus when the menu closes:

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    // Open UI and capture input: mp.cef.setFocus(keyboardFocus, mouseCursor)
    mp.commands.add('ui', () => {
      mp.cef.setFocus(true, true);
      console.log('UI in focus:', mp.cef.isInFocus());
    });

    // Close UI and return control to the game
    mp.commands.add('closeui', () => {
      mp.cef.setFocus(false, false);
      console.log('UI in focus:', mp.cef.isInFocus());
    });

    // Handle events coming from the CEF page
    mp.events.onCef('uiClickEvent', (message) => {
      console.log(`[Client Script] Received: ${message}`);

      // Respond back into the CEF web view
      mp.events.emitCef('acknowledgeData', 'Data received by client script!');
    });
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    -- Open UI and capture input: mp.cef.setFocus(keyboardFocus, mouseCursor)
    mp.commands.add('ui', function()
      mp.cef.setFocus(true, true)
      print("UI in focus:", mp.cef.isInFocus())
    end)

    -- Close UI and return control to the game
    mp.commands.add('closeui', function()
      mp.cef.setFocus(false, false)
      print("UI in focus:", mp.cef.isInFocus())
    end)

    -- Handle events coming from the CEF page
    mp.events.addCef('uiClickEvent', function(message)
      print("[Client Script] Received: " .. message)

      -- Respond back into the CEF web view
      mp.events.triggerCef('acknowledgeData', 'Data received by client script!')
    end)
    ```
  </TabItem>
</Tabs>

### Testing In-Game

1. Connect to your development server.
2. Press `F8` to open the client developer console.
3. Type `ui` and press Enter. The mouse cursor appears over the screen.
4. Click **Send Data to Client**. The status text updates with the reply payload.
5. Type `closeui` to release cursor control back to gameplay.

## Remote Debugging CEF

To inspect HTML/CSS elements and view the web console:

1. Add `cef_debug = true` to your [`server.toml`](/reference/server/configuration).
2. Connect to the server with the game client.
3. Open a Chromium-based browser (Chrome, Edge, Brave) and navigate to `http://localhost:9222`.
4. Select the target page to launch Chrome DevTools.
