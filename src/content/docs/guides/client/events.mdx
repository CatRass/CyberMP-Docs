The client-side event system is the primary communication bridge for your scripts. It enables you to react to platform lifecycles, coordinate streaming entities, communicate with the server, and interact with the Chromium Embedded Framework (CEF) user interface.

In this guide, you will learn how to handle local, network, and browser events using JavaScript and Lua.

---

## Custom & Platform Events

Platform events are fired automatically by the client runtime when engine states change (e.g. resources starting, entities streaming in). You can also emit custom local events within your client environment.

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    // 1. Platform Event: Triggers when this client resource fully starts
    mp.events.on('resourceStart', () => {
      console.log('The client resource has successfully started.');
    });

    // 2. Platform Event: Triggers when an entity enters streaming range
    mp.events.on('vehicleStreamIn', (netID, gameID) => {
      console.log(`Vehicle streamed in - NetID: ${netID}, GameID: ${gameID}`);
    });

    // 3. Custom Local Event: Listening for a local signal
    mp.events.on('myCustomEvent', (data) => {
      console.log('Received local data:', data);
    });

    // Emitting a custom local event
    mp.events.emit('myCustomEvent', { status: 'ok', timestamp: Date.now() });
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    -- 1. Platform Event: Triggers when this client resource fully starts
    mp.events.add('resourceStart', function()
      print('The client resource has successfully started.')
    end)

    -- 2. Platform Event: Triggers when an entity enters streaming range
    mp.events.add('vehicleStreamIn', function(netID, gameID)
      print(string.format("Vehicle streamed in - NetID: %s, GameID: %s", netID, gameID))
    end)

    -- 3. Custom Local Event: Listening for a local signal
    mp.events.add('myCustomEvent', function(data)
      print('Received local data:', data)
    end)

    -- Emitting a custom local event
    mp.events.trigger('myCustomEvent', { status = 'ok', timestamp = os.time() })
    ```
  </TabItem>
</Tabs>

## Communicating with the Server

Client scripts send payloads to the server and listen for network broadcasts dispatched by the server runtime.

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    // Send a reliable packet to the server
    mp.events.emitServer('requestVehicleSpawn', 'Vehicle.v_sport1_quadra_turbo_r_player');

    // Listen for events dispatched from the server
    mp.events.onServer('serverNotification', (message) => {
      console.log(`[Server]: ${message}`);
    });
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    -- Send a reliable packet to the server
    mp.events.triggerServer('requestVehicleSpawn', 'Vehicle.v_sport1_quadra_turbo_r_player')

    -- Optional: Send over the unreliable channel (e.g. high-frequency inputs)
    -- Syntax: triggerUnreliable(name, sendRateBps, ...)
    mp.events.triggerUnreliable('playerInputTick', 30, { moving = true })

    -- Listen for events dispatched from the server
    mp.events.addServer('serverNotification', function(message)
      print(string.format("[Server]: %s", message))
    end)
    ```
  </TabItem>
</Tabs>

## Interacting with CEF (Browser UI)

When building user interfaces with HTML, CSS, and JavaScript, use CEF events to pass data between the game client and your web page.

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    // Built-in CEF Event: Fires when the browser finishes parsing the document
    mp.events.onCef('domReady', (frameName) => {
      console.log(`Browser frame '${frameName}' is ready.`);

      // Send initial data to the CEF web page
      mp.events.emitCef('initializeDashboard', { playerName: 'V', health: 100 });
    });

    // Built-in CEF Event: Handle page errors
    mp.events.onCef('loadingFailed', (error) => {
      console.error(`CEF Load Failed: ${error.message} (Frame: ${error.frameName})`);
    });

    // Custom Event: Dispatched from the CEF web page via mp.events.emit
    mp.events.onCef('uiAction', (actionName, payload) => {
      console.log(`User triggered UI action: ${actionName}`, payload);
    });
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    -- Built-in CEF Event: Fires when the browser finishes parsing the document
    mp.events.addCef('domReady', function(frameName)
      print(string.format("Browser frame '%s' is ready.", frameName))

      -- Send initial data to the CEF web page
      mp.events.triggerCef('initializeDashboard', { playerName = 'V', health = 100 })
    end)

    -- Built-in CEF Event: Handle page errors
    mp.events.addCef('loadingFailed', function(error)
      print(string.format("CEF Load Failed: %s", error))
    end)

    -- Custom Event: Dispatched from the CEF web page via mp.events.emit
    mp.events.addCef('uiAction', function(actionName, payload)
      print(string.format("User triggered UI action: %s", actionName))
    end)
    ```
  </TabItem>
</Tabs>

## Cleaning Up Listeners

To prevent memory leaks or duplicate handlers when resources reload, detach listeners when they are no longer needed.

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    const handleVehicleStream = (netID, gameID) => {
      console.log(`Vehicle ${netID} streamed in.`);
    };

    // Register listener
    mp.events.on('vehicleStreamIn', handleVehicleStream);

    // Unregister listener
    mp.events.off('vehicleStreamIn', handleVehicleStream);
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    local function handleVehicleStream(netID, gameID)
      print(string.format("Vehicle %s streamed in.", netID))
    end

    -- Register listener (add returns a handler token or accepts named function)
    local token = mp.events.add('vehicleStreamIn', handleVehicleStream)

    -- Unregister listener
    mp.events.remove(token)
    ```
  </TabItem>
</Tabs>

## Client Platform Events Reference

| Event Name | Arguments | Description |
| :--- | :--- | :--- |
| `resourceStart` | `()` | Triggered when the client resource has fully initialized. |
| `resourceStop` | `()` | Triggered immediately before the resource is unloaded. |
| `vehicleStreamIn` | `(netID, gameID)` | A synchronized vehicle entered client streaming range. |
| `vehicleStreamOut` | `(netID, gameID)` | A synchronized vehicle left client streaming range. |
| `remotePlayerStreamIn` | `(netID, gameID)` | Another player entered client streaming range. |
| `remotePlayerStreamOut`| `(netID, gameID)` | Another player left client streaming range. |
| `objectStreamIn` | `(netID, gameID)` | A synchronized world object entered streaming range. |
| `objectStreamOut` | `(netID, gameID)` | A synchronized world object left streaming range. |
| `pedStreamIn` | `(netID, gameID)` | A synchronized ped (NPC) entered streaming range. |
| `pedStreamOut` | `(netID, gameID)` | A synchronized ped (NPC) left streaming range. |
| `pickupStreamIn` | `(netID, gameID)` | A synchronized pickup item entered streaming range. |
| `pickupStreamOut` | `(netID, gameID)` | A synchronized pickup item left streaming range. |
| `doorStreamIn` | `(netID, gameID)` | A synchronized door entity entered streaming range. |
| `doorStreamOut` | `(netID, gameID)` | A synchronized door entity left streaming range. |
| `domReady` | `(frameName)` | A CEF browser frame completed DOM construction. |
| `loadingFailed` | `(error)` | A CEF browser instance encountered a network or render error. |
