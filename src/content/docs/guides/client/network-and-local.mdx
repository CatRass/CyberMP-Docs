In CyberMP, the server identifies entities using lightweight **Network IDs** (`netId`), while REDengine tracks entities in memory using internal **Game IDs** (`gameId` / `EntityID`). Passing a `netId` directly into a game native or transmitting a local `gameId` to the server will result in lookup failures.

For complete API signatures and types, see the [`MpNetwork`](/reference/client/api/global/mpnetwork/) and [`MpLocal`](/reference/client/api/global/mplocal/) references, or the [Lua Client API Reference](/reference/lua/client/).

---

## ID Translation (`mp.network`)

When an entity enters streaming range, the client receives both its `netID` and its active `gameID`. The `mp.network` namespace provides helper functions to convert between them:

| Method | Return Value | Target Entity Type |
| :--- | :--- | :--- |
| `getVehicleGameId(netId)` / `getVehicleId(gameId)` | `gameId` or `netId` | Vehicles |
| `getPlayerGameId(netId)` / `getPlayerId(gameId)` | `gameId` or `netId` | Connected Players |
| `getPedGameId(netId)` / `getPedId(gameId)` | `gameId` or `netId` | Pedestrians / NPCs |
| `getObjectGameId(netId)` / `getObjectId(gameId)` | `gameId` or `netId` | World Objects |
| `getLocalPlayerId()` | `number` | The local client's permanent Network ID |
| `getStreamedPlayers()` | `Array<gameId>` | All remote players currently streamed in |
| `getStreamedPool(poolName)` | `Array<gameId>` | Entities in `'CVehicle'`, `'CPed'`, `'CObject'`, `'CPickup'` |
| `getServerAddress()` | `string` | Connected session endpoint (e.g. `127.0.0.1:2077`) |

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    mp.events.on('vehicleStreamIn', (netID, gameID) => {
      // Look up entity metadata using netID
      const isLocked = mp.meta.getEntityMeta(netID, 'locked');

      // Convert gameID back to netID
      const originalNetID = mp.network.getVehicleId(gameID);

      console.log(`Streamed vehicle: NetID=${netID}, GameID=${gameID}, Locked=${isLocked}`);
    });

    const localNetID = mp.network.getLocalPlayerId();
    const streamedPlayers = mp.network.getStreamedPlayers();
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    mp.events.add('vehicleStreamIn', function(netID, gameID)
      -- Look up entity metadata using netID
      local isLocked = mp.meta.getEntity(netID, 'locked')

      -- Convert gameID back to netID
      local originalNetID = mp.network.getVehicleId(gameID)

      print(string.format("Streamed vehicle: NetID=%s, GameID=%s, Locked=%s", netID, gameID, tostring(isLocked)))
    end)

    local localNetID = mp.network.getLocalPlayerId()
    local streamedPlayers = mp.network.getStreamedPlayers()
    ```
  </TabItem>
</Tabs>

:::caution[Streaming Range Requirement]
ID conversions are only valid while the entity is currently within streaming range. An entity that has despawned or not yet streamed into the client scene has no active `gameID`.
:::

## Client-Only Entities (Local Spawn)

You can spawn vehicles, peds, and props that exist **strictly on the local client**. Other connected players will not see or interact with them. This is ideal for dealership showcase rooms, cinematic camera sequences, or decorative UI scenes:

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    // Client-side hashes must be 64-bit BigInt values in JavaScript
    const modelHash = BigInt(mp.game.hashes.toTweakdbid('Vehicle.v_standard2_archer_hella'));
    const appearanceHash = BigInt(mp.game.hashes.toCname('default'));

    // Spawn local preview vehicle: (model, appearance, x, y, z, roll, pitch, yaw, streaming)
    const vehHandle = mp.local.spawnVehicle(
      modelHash,
      appearanceHash,
      -1392.637, 1271.536, 123.082,
      0.0, 0.0, 90.0,
      true
    );

    // Despawn when no longer needed
    mp.local.despawnVehicle(vehHandle);
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    -- Lua hash helpers return decimal strings; convert to numbers
    local modelHash = tonumber(mp.hashes.toTweakdbid('Vehicle.v_standard2_archer_hella'), 10)
    local appearanceHash = tonumber(mp.hashes.toCname('default'), 10)

    -- Spawn local preview vehicle: (model, appearance, x, y, z, roll, pitch, yaw, streaming)
    local vehHandle = mp.client.spawnVehicle(
      modelHash,
      appearanceHash,
      -1392.637, 1271.536, 123.082,
      0.0, 0.0, 90.0,
      true
    )

    -- Despawn when no longer needed
    mp.client.despawnVehicle(vehHandle)
    ```
  </TabItem>
</Tabs>

Similar methods exist for pedestrians (`spawnPed` / `despawnPed`) and objects (`spawnObject` / `despawnObject`). Note that local entities in JavaScript reside under [`mp.local.*`](/reference/client/api/global/mplocal/), whereas in Lua they reside under [`mp.client.*`](/reference/lua/client/#local-entities-mpclient).

## Per-Frame Tick Loops

When implementing custom 3D markers, distance math, or camera updates, execute logic on every render frame:

<Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
  <TabItem label="JS">
    ```js title="client.js"
    let tickId = null;

    const startTick = () => {
      if (tickId !== null) return;

      tickId = mp.setTick(() => {
        const player = mp.game.GetPlayer();
        if (!player) return;
        // Fast calculations: distance checks, raycasts, UI positioning
      });
    };

    const stopTick = () => {
      if (tickId === null) return;
      mp.clearTick(tickId);
      tickId = null;
    };

    mp.events.on('resourceStop', stopTick);
    ```
  </TabItem>
  <TabItem label="Lua">
    ```lua title="client.lua"
    local isRunning = true

    -- mp.onUpdateLoop runs on every render frame
    mp.onUpdateLoop(function()
      if not isRunning then return end

      local player = Game.GetPlayer()
      if not player then return end
      -- Fast calculations: distance checks, raycasts, UI positioning
    end)

    mp.events.add('resourceStop', function()
      isRunning = false
    end)
    ```
  </TabItem>
</Tabs>

:::tip[Performance]
Never perform database operations, heavy JSON parsing, or bulk entity queries inside a tick callback. Keep tick execution under 1 millisecond to prevent frame drops.
:::

## Engine Timer & Launcher Settings

- **`mp.getTimer()`**: Returns the number of milliseconds elapsed since the game engine shell was initialized.
- **`mp.getLauncherSettings()`**: Reads the current client launcher configuration (e.g. selected language, graphics presets).
