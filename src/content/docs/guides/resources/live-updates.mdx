One of the most powerful features of the CyberMP Server is the ability to update your scripts without restarting the entire server process. This is essential for fast iteration and debugging.

### Prerequisites
- A running CyberMP Server.
- Access to the Server Console.
- An active resource (e.g., the `hello_world` resource from the [previous](/guides/resources/creating-resource) guide).

### Steps

<Steps>
    1. #### Modify the Script

        <Tabs syncKey={SCRIPT_LANG_TAB_SYNC_KEY}>
            <TabItem label="JS">
                Open `resources/hello_world/server.js` and add a new line of code:

                ```js title="server.js" ins={2}
                console.log('Hello World from CyberMP Server!');
                console.log("The resource has been updated live!");
                ```
            </TabItem>
            <TabItem label="Lua">
                 Open `resources/hello_world/server.lua` and add a new line of code:

                ```lua title="server.lua" ins={2}
                print("Hello World from CyberMP Server!")
                print("The resource has been updated live!")
                ```
            </TabItem>
        </Tabs>

    2. #### Issue the Restart Command
        In your Server Console, execute the restart command followed by your resource folder name:
        ```shell
        restart hello_world
        ```

    3. #### Verify the Output
        The server will immediately stop the old instance and initialize the new code. You should see the updated logs appear:

        The following content should be in your console:
        ```ansi
        [38;2;179;133;0m[00:00:00] [Resources][0m Stopped resource hello_world
        [38;2;179;133;0m[00:00:00] [script:hello_world][0m Hello World from CyberMP Server!
        [38;2;179;133;0m[00:00:00] [script:hello_world][0m The resource has been updated live!
        [38;2;179;133;0m[00:00:00] [Resources][0m Loaded resource hello_world
        >
        ```

</Steps>

## Client-Side Updates

The restart command also applies to Client Scripts. When you restart a resource on the server, all connected clients will automatically re-download and restart that specific resource's client-side logic.

## Automated Updates

If you find manually typing restart inconvenient during heavy development, you can automate this process.

Check out the [Hotreload](/guides/recipes/hotreload) Guide to learn how to set up an automated development environment.
